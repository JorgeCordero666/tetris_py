# Juego de TETRIS hecho en Python
## Antes de empezar
**Resolver estos ejercicios antes de empezar:**
1. Crear una matriz de 5 filas y 5 columnas y modificar una celda concreta.
2. Dada una columna y el ancho de una pieza, determinar si cabe en un tablero de 10 columnas.
3. Dada una posición, calcular las nuevas coordenadas al mover una pieza a la izquierda, derecha o abajo.
4. Determinar si una posición propuesta coincide con una celda ocupada o sale del tablero.
5. Recorrer una matriz e identificar cuáles de sus filas están completamente ocupadas.

## Objetivos de desarrollo
- [ ] 1. Crear el tablero
    * Representar una matriz y mostrar sus celdas.
- [ ] 2. Dibujar una pieza
    * Mostrar una pieza fija formada por cuatro bloques.
- [ ] 3. Mover la pieza
    * Permitir movimiento horizontal con el teclado.
- [ ] 4. Implementar colisiones
    * Impedir movimientos fuera del tablero o contra bloques.
- [ ] 5. Agregar gravedad
    * Hacer que la pieza baje automáticamente.
- [ ] 6. Fijar pieza
    * Integrar al tablero una pieza que ya no puede bajar.
- [ ] 7. Limpiar filas
    * Detectar y eliminar filas completas.
- [ ] 8. Completar la lógica del juego
    - [ ] Girar las piezas sin deformarlas ni atravesar obstáculos.
    - [ ] Preparar una pieza futura y mostrarla en pantalla.
    - [ ] Asignar puntos según las filas eliminadas.
    - [ ] Acelerar la caída conforme avanza la partida.
    - [ ] Reconocer cuándo ya no se puede colocar una pieza nueva.
    - [ ] Restablecer el juego sin cerrar la aplicación.
    - [ ] Detener y continuar la partida conservando su estado.
    - [ ] Comprobar que las reglas funcionan en situaciones límite.
- [ ] 9. Implementar interfaz grafica
